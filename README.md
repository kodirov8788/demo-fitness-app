# Demo Fitness App

A modern fitness-oriented web application exploring forms, state synchronization, and data-driven user flows.

**Live demo:** https://demo-fitness-app.vercel.app

## What This Project Shows
- Product UI work around user input and goal-oriented flows
- Server/client data coordination using query-based patterns
- Stronger form validation than a basic static fitness landing page

## Why This Stack / Tooling
- **Next.js 16 + React 19** provide a current app foundation for a responsive product UI.
- **TanStack Query** is useful when frontend state depends on async server-style data sources.
- **Firebase** is a practical managed backend choice for an app that needs quick iteration.
- **react-hook-form + zod** improve correctness in form-heavy interactions.
- **Radix UI primitives** help build accessible controls like sliders, selects, and radio groups.

## Stack
- Next.js 16
- React 19
- TypeScript
- Firebase
- TanStack Query
- Zod + react-hook-form

## Key Features
- Fitness-focused user flows
- Form-heavy interaction patterns
- Query-based data handling and validation
- Modern component architecture
